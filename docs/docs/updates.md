# Updates

They are done automatically every 15 minutes. You can also check for updates manually using the "Lab Update Monitor" application, which will show you if there are any updates available and let you install them with a single click and a password prompt.

## Switching branches

From the same application you can switch the repository at `/etc/nixos` to a different branch (e.g. to try a testing/staging branch). Pick "Cambiar de rama del repositorio" from the menu, choose a branch, and enter the admin password when prompted — this checks out the branch and rebuilds the system, same as a regular update.
